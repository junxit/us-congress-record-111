# BUDGET COMMITTEE PERMISSION TO FILE

```
                  BUDGET COMMITTEE PERMISSION TO FILE

  Mr. REID. Mr. President, I ask unanimous consent that on Friday, 
March 27, the Budget Committee be permitted to file the committee-
reported concurrent resolution on the budget, and they be allowed to do 
this between the hours of 11 a.m. and 1 p.m.
  The PRESIDING OFFICER. Without objection, it is so ordered.
```
